# Taller de Costura

Aplicación web para administrar el catálogo de productos y el seguimiento de pedidos.

## Ejecución local

Requiere Python 3. Desde esta carpeta, ejecuta:

```powershell
python server.py
```

Abre `http://localhost:8080` en el navegador. La aplicación crea `tienda.db` localmente para guardar sus datos.
